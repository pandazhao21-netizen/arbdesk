📈 Pin edge → mode rules

vig ≤ %edge > %edge ≤ %mode
When an alert has a pin ref line, vig + edge are computed and the first matching band (top to bottom) sets the mode, overriding the bookie rule. Leave edge-max blank for "no upper limit". A row with vig above its "vig ≤ %" always → balanced.

💰 Staking parameters

Extra-bet staking rule (fixed): size the unhedged extra by Kelly on the pin edge, with —
• floor: only bet if pin edge ≥ the edge-floor setting (below → no extra bet)
• haircut: subtract 0.5% from the edge before sizing
• edge cap: cap the sizing edge at 5% (guards against stale-price readings)
• vig tier: full Kelly at pin vig ≤ 8%, half Kelly above
• per-bet cap: stake never exceeds 2% of bankroll
• rounding: nearest 10 under 100, else nearest 100
Adjustable: Kelly multiplier, Bankroll, and Edge floor. Exports/imports with settings.
